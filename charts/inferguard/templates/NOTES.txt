Your InferGuard operator has been deployed successfully!

To get started:

1. Check the deployment status:
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "inferguard.name" . }}

2. View the service:
   kubectl get svc {{ include "inferguard.fullname" . }} -n {{ .Release.Namespace }}

3. Create a sample ModelRelease:
   kubectl apply -f config/samples/modelrelease_v1alpha1_modelrelease.yaml

4. Check the ModelRelease status:
   kubectl get modelreleases -n {{ .Release.Namespace }}

5. View operator logs:
   kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/name={{ include "inferguard.name" . }}

6. Access Prometheus metrics:
   kubectl port-forward svc/{{ include "inferguard.fullname" . }} 8080:8080
   curl http://localhost:8080/metrics

For more information, visit: https://github.com/gfhw/inferguard
